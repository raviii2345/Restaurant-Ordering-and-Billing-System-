# Restaurant Ordering and Billing System

A Python-based console application for restaurant food ordering, billing, and payment processing.

## Project Overview

The Restaurant Ordering and Billing System is designed to make the process of ordering food and generating a bill simple and efficient.

The application allows a customer to:

- Enter their name
- View the restaurant menu
- Select multiple food items
- Enter the quantity of each item
- Calculate item-wise totals
- Calculate the subtotal
- Add 5% GST
- Add a fixed ₹40 delivery charge
- Select a payment method
- Generate a final receipt

## Technologies Used

- Python 3
- Functions
- Dictionaries
- Lists
- Loops
- Conditional statements
- Arithmetic operations
- Console input and output
