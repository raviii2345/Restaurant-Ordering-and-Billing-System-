# Project Statement

## Title

**Restaurant Ordering and Billing System**

## Problem Statement

In restaurants, taking food orders and calculating bills manually can take time and may lead to calculation errors.

The purpose of this project is to develop a simple Python-based Restaurant Ordering and Billing System that allows customers to select food items, enter quantities, calculate the total bill, and choose a payment method.

## Objectives

The main objectives of this project are:

- To display a restaurant menu.
- To allow customers to select multiple food items.
- To accept the quantity of each selected item.
- To calculate the price of each ordered item.
- To calculate the subtotal.
- To calculate 5% GST.
- To add a fixed delivery charge of ₹40.
- To calculate the final bill amount.
- To provide different payment options.
- To generate a final receipt.

## Scope of the Project

This project is a console-based application developed using Python.

The system provides basic restaurant ordering and billing functionality. It is suitable for learning Python programming concepts such as functions, dictionaries, lists, loops, conditional statements, and user input.

## Technologies Used

- Python 3
- Git
- GitHub

## Main Features

1. Customer name input
2. Restaurant menu display
3. Multiple item selection
4. Quantity input
5. Item-wise price calculation
6. Subtotal calculation
7. 5% GST calculation
8. ₹40 delivery charge
9. Cash payment option
10. UPI payment option
11. Card payment option
12. Final receipt generation
